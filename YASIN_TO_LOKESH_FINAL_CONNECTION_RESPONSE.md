## 3. Audio Input Contract (Gateway $\rightarrow$ Voice Engine)

Verified against `backend/app/services/telephony/audio_codec.py`, `transcoding.py`, and `voice_engine_client.py`:

* **Codec:** Linear PCM16 (Raw uncompressed signed 16-bit integers)
* **Sample Rate:** `16,000 Hz` (16 kHz)
* **Bit Depth:** `16-bit` (2 bytes per sample)
* **Channels:** `1` (Mono)
* **Endianness:** Little-endian (`<h`)
* **Frame Duration:** `20 milliseconds` (0.020 s)
* **Bytes Per Frame:** **`640 bytes`** ($16000 \times 1 \times 2 \times 0.020 = 640$)
* **Transport:** 
  * **Option A (Preferred / Native):** Pure binary WebSocket frames containing 640 bytes of raw PCM16.
  * **Option B (JSON Fallback):** `{"event": "audio.input", "data": "<base64_pcm16>", "seq": 101}`.
* **WAV / RIFF Headers:** **STRICTLY PROHIBITED**. Raw audio stream only.
* **Audio Direction:** Inbound (Caller speech sent to Voice Engine STT/VAD).

### Inbound Transcoding Pipeline

```
Exotel Carrier (PSTN)
  │  Format: G.711 μ-law (PCMU)
  │  Sample Rate: 8,000 Hz / Mono
  │  Frame Duration: 20 ms (160 bytes)
  ▼
Yasin Voice Gateway (audio_codec.py / transcoding.py)
  │  Step 1: Decompress: audioop.ulaw2lin(chunk, 2) -> PCM16 @ 8 kHz (320 bytes)
  │  Step 2: Upsample:   audioop.ratecv(..., 8000, 16000, ...) -> PCM16 @ 16 kHz (640 bytes)
  ▼
Lokesh Voice Engine (wss://voice-test.gentechs.in/ws/voice)
     Format: Linear PCM16
     Sample Rate: 16,000 Hz / Mono
     Frame: 640 bytes raw binary / 20 ms
```
